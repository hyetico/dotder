# 0004. 폴더 모양은 목록 카드에서만 쓴다

- 날짜: 2026-11-21
- 상태: 확정

## 배경

프로젝트 디테일 페이지가 큰 폴더 틀 안에 들어 있었다. 화면 높이를 고정하고 왼쪽·오른쪽이 따로 스크롤됐고, 탭이 세 겹(폴더 탭 → 개요/목표/태스크/팀 → 요약/타임라인/변경 이력)이었다.

## 결정

- 폴더 모양은 **프로젝트 목록의 카드**에서만 쓴다.
- 디테일 페이지는 일반 페이지 규칙을 따른다. 페이지 전체가 스크롤되고, 탭 줄은 하나만 둔다.
- 디테일 페이지에서는 프로젝트 색을 이름 앞 점이나 아이콘에만 쓴다.

- 구조는 `design-guide.md` 6장, `layout-guide.md` 5-2를 따른다.
