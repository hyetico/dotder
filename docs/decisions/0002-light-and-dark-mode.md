# 0002. 라이트 모드와 다크 모드를 모두 지원한다

- 날짜: 2026-11-21
- 상태: 확정

## 배경

`globals.css`에 다크 모드 값이 일부만 있었다. `--color-text-secondary`, `--color-text-muted`, `--color-hover`, `--color-primary` 등이 빠져 있어서 켜면 어두운 배경에 어두운 글자가 나온다. 컴포넌트에도 `bg-white` 86개, `text-black` 21개, `bg-black` 10개처럼 모드와 상관없이 고정된 색이 많다.

## 결정

- v1에서 **라이트 · 다크 · 시스템 설정 따르기** 세 가지를 지원한다.
- 설정 페이지 "보기" 섹션에 테마 선택을 둔다. 기본값은 "시스템".
- 모든 색 토큰은 라이트와 다크 값을 **둘 다** 가진다. 한쪽만 있는 토큰은 만들지 않는다.
- 컴포넌트에서 `bg-white`, `text-black`, `#ffffff` 같은 고정 색을 쓰지 않는다. `--color-surface`, `--color-text` 같은 토큰을 쓴다.
- 프로젝트 색(팔레트)도 다크용 값을 따로 둔다. (`projectColors.ts`에 이미 다크용 계산이 일부 있음)

## 결과

- `style-guide.md`의 모든 색 표에 라이트/다크 두 열이 있다.
- 토큰 정리 단계(roadmap 4단계)에서 고정 색을 먼저 없애고, 설정 단계(8단계)에서 테마 전환을 붙인다.
