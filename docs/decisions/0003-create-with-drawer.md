# 0003. 만들기는 드로어 하나로, 필수 입력은 이름만

- 날짜: 2026-11-21
- 상태: 확정

## 배경

목표·메모는 드로어로 만드는데 프로젝트는 3단계 위저드 페이지로 만들었다. 위저드는 10개 항목을 정해야 하고 마감일이 필수라서, "생각나면 바로 남긴다"는 앱 성격과 맞지 않았다.

## 결정

- 프로젝트·목표·메모(나중에 태스크도) 생성은 **같은 구조의 오른쪽 드로어**로 한다.
- 필수 입력은 **이름 하나**. 마감일은 비워도 된다.
- 상태는 날짜로 자동 계산한다.
- 목표 태그·메인 설정은 "추가 설정"에 접는다. (팀은 v1에 없음, PRD 5-4)
- 위저드는 삭제하지 않고, 첫 프로젝트를 만들 때 온보딩으로 쓸지 나중에 결정한다.
- 많은 항목을 고치는 "프로젝트 수정"은 계속 별도 페이지로 둔다.

## 대체한 규칙

- 예전 규칙 "프로젝트 생성/수정은 별도 Page" (삭제됨)
