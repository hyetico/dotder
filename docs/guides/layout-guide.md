# 레이아웃 가이드

> 상태: v0.3 · 2026-11-23
> **디자인 값의 원본은 `design/boards/docs/` (handoff)입니다. 이 문서는 코드 쪽 이름과 쓰는 곳을 적습니다.** 값이 다르면 원본을 따르고, handoff를 받으면 `design/_handoff/CHANGES-*.md` 목록대로 이 문서도 고칩니다.
> "화면 뼈대"를 다룹니다. 값은 [style-guide](style-guide.md)의 토큰을 씁니다.

## 1. 앱 골격

```
┌──────────┬──────────────────────────────────────────┐
│          │ 헤더 56px (브레드크럼 · 검색 · 페이지 액션)  │
│ 사이드바  ├──────────────────────────────────────────┤
│ 245px    │ 탭 줄 (있을 때)                           │
│          │                                          │
│          │ 본문 (최대 1200px)  ← 페이지 전체가 스크롤   │
│          │                                          │
└──────────┴──────────────────────────────────────────┘
                                    └ 드로어가 열리면 오른쪽에 붙음
```

- 공통 골격은 `components/layout/AppLayout.tsx`, 대시보드 화면은 `app/(dashboard)/layout.tsx`가 감싼다.
- **페이지 전체가 스크롤되는 것이 기본이다.** 화면 높이를 고정하고 영역마다 따로 스크롤하지 않는다.
- 예외 (문서에 적힌 것만 허용):
  - 태스크 보드: 가로 스크롤
  - 태스크 캘린더: `--tasks-calendar-height`로 높이 고정
  - 드로어·모달 본문: 안쪽 스크롤

## 2. 반응형 기준점

| Tailwind | 너비 | 바뀌는 것 |
|---|---|---|
| (기본) | 0~767 | 모바일. 사이드바 숨김(메뉴 드로어), 하단 앱 바, 카드 1열, 드로어 전체 화면 (원본은 하단 탭 바 없음 · ☰ → 왼쪽 시트 300 · 드로어·팝오버·모달은 바텀시트 — roadmap 5단계) |
| `md:` | 768~ | 태블릿. 카드 2열, 페이지 여백 24, 드로어 400 |
| `lg:` | 1024~ | 데스크톱. 사이드바 펼침, 드로어가 본문을 밀어냄, 페이지 여백 32. 1024~1279는 사이드바 64로 접힘(펼치기 가능), 1280부터 펼침 |
| `xl:` | 1280~ | 넓은 데스크톱. 페이지 여백 32, 카드 3열 |
| `2xl:` | 1440~ | 아주 넓은 화면. 본문은 1200에서 멈추고 가운데. Tailwind 기본(1536) 대신 globals.css `@theme`에서 1440(90rem)으로 지정 |

- **Tailwind 이름만 쓴다.** `min-[1025px]:`, `min-[1024px]:`, `max-[1024px]:` 같은 임의 값 금지.
- "이 크기 미만"은 `max-lg:`처럼 Tailwind의 `max-*`를 쓴다.
- globals.css의 `@media`도 같은 값(768/1024/1280/1440)만 쓴다.

## 3. 사이드바

- 너비 `--sidebar-width`(245), 접으면 `--sidebar-collapsed-width`(64).
- 순서: 로고 → 메인 프로젝트(설정에서 켰을 때) → 메뉴(프로젝트·목표·태스크·메모) → 구분 → 설정 → 아래쪽 이번 주 진행률 · 프로필
- 로고는 `<h1>`이 아니다. 페이지의 `<h1>`은 페이지 제목 하나뿐이다.
- 팀·리포트는 PRD 결정에 따라 v1 메뉴에서 숨긴다. 플레이그라운드는 개발 환경에서만 보인다.

## 4. 헤더

- 높이 `--header-height`(56).
- 왼쪽: 브레드크럼 (`프로젝트 › 프로젝트 이름`)
- 오른쪽: 검색, 페이지 주 버튼
- 페이지별 액션은 `HeaderActions`로 넣는다. 모바일에서는 `···` 메뉴로 접는다.

## 5. 페이지 종류별 뼈대

### 5-1. 목록 페이지 (프로젝트·목표·태스크·메모)

> 아래 순서는 지금 코드 기준이다. 원본은 **제목 + 한 줄 요약 → 탭 40 → 툴바 36 → 내용** (간격 32 · 24 · 24 · 24)이며, 5단계에서 바꾼다.

```
탭 줄                         [전체][메인][즐겨찾기][맞춤…][+]
   ↕ 32 (--page-title-above)
페이지 제목  ← PageHeading
   ↕ 8  (--page-title-gap)
설명
   ↕ 32 (--page-title-below)
요약 카드 줄 (선택)
   ↕ 24 (--section-gap)
검색 · 상태 필터 칩 · 정렬 · 보기 전환
   ↕ 24
목록 / 카드 그리드
```

- 제목과 설명은 `PageHeading`, 바깥 여백은 `PageInset`. 직접 `<h1>` 금지.
- `PageInset`의 `top="page"`가 위 32px, 제목 아래 32px은 `PageHeading` 안에 있다.
- 제목을 `space-y`·`gap` 안에 넣어 간격을 더하지 않는다. 제목 다음 블록부터 묶는다.
- 드로어가 열려 본문이 좁아져도 제목 간격은 그대로다.

### 5-2. 디테일 페이지 (프로젝트)

```
헤더: 프로젝트 › 이름                       [☆][수정][···]
   ↕ 32
● 이름                ← PageHeading (아이콘 슬롯 사용)
  설명 한 줄 · 더보기
  메타 칩 줄 (기간·D-day · 상태 · 태그)
   ↕ 24
탭 줄 [개요][목표][태스크][메모][기록]
   ↕ 32
본문
  lg 이상: 2열 grid (2fr : 1fr), 간격 32
  lg 미만: 1열
```

- 폴더 틀을 쓰지 않는다. ([0004](../decisions/0004-folder-only-in-list.md))
- 탭은 주소와 연결한다: `/projects/[id]`, `/projects/[id]/goals`, `/projects/[id]/tasks` …

### 5-3. 설정 페이지

- 배경 `--color-page`, 가운데 정렬, 최대 너비 760.
- 섹션 제목(`text-caption` 굵게) + 카드(`--color-surface`, `--radius-lg`) 안에 설정 행.
- 설정 행: 왼쪽 제목·설명(최소 260), 오른쪽 컨트롤. 좁으면 줄바꿈.

### 5-4. 수정 페이지 (프로젝트 수정 등)

- 가운데 정렬, 최대 너비 880.
- 제목은 `PageHeading`의 `variant="form"` (★ 새로 추가). 지금 5곳이 `<h1>`을 직접 쓴다.
- 하단 고정 바(`BottomAppBar`)에 취소·저장. 높이 `--bottom-app-bar-height`.

## 6. 드로어

```
┌─ --drawer-width (400) ────────────────┐
│ 상단 바 60  [닫기]          [전체 화면] │  좌우 20
│ 본문  좌우 --drawer-padding-x (56)     │  ← 이 영역만 스크롤
│  아이콘 블록 48                         │
│   ↕ 16                                 │
│  제목 입력 (text-page-title)            │
│   ↕ 24 + 구분선                         │
│  라벨 80 │ 값        (행 위아래 16)      │
│ 하단 바  좌우 24, 위아래 16, 위 구분선    │
└───────────────────────────────────────┘
```

| 화면 | 동작 |
|---|---|
| `lg` 이상 | 본문을 드로어 너비만큼 밀어냄 (`--drawer-offset`), 오버레이 없음 |
| `md` ~ `lg` | 오버레이(`--color-overlay`) 위에 덮음 |
| `md` 미만 | 전체 화면, 본문 좌우 20 |

- 너비는 웹·태블릿 모두 400이다.
- 위 그림의 안쪽 모양(상단 바 60, 본문 좌우 56, 라벨 80 행)은 지금 코드 기준이다. 원본은 헤더 56 · 본문 패딩 24 · 필드 간격 24 · 푸터 72이며, 6단계에서 바꾼다.
- "전체 화면" 버튼: 본문 최대 너비 760, 가운데.
- 지금은 목표 드로어만 밀어내기를 지원한다(`--drawer-offset`). 공통 드로어로 옮긴다.

## 7. 모달

| 종류 | 너비 |
|---|---|
| 모달 (폼 · 선택 · 설정 · 맞춤 탭 추가 · 내보내기) | 480 (`--modal-width`) |
| 확인창 (`AlertModal`) | 320 (`--confirm-width`). 드로어 안에서 열면 드로어 가운데 |
| 통합 검색 | 600 (`--search-width`), 위에서 88 |

- `md` 미만에서는 아래에서 올라오는 시트로 바꾼다. 확인창만 모바일에서도 가운데에 둔다.
- 드로어 위에 모달을 겹치지 않는다. 드로어 안에서는 팝오버로 처리한다.

## 8. 그리드

| 화면 | 기본 | md | lg | xl |

| 폴더 카드 | 1열 | 2열 | 3열 | `repeat(auto-fill, minmax(260px, 1fr))` |
